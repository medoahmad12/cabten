# كابتن بارتي - الحزمة الأولى

## طريقة التطبيق
1. انسخ محتويات هذا المجلد فوق مشروعك (اقبل استبدال الملفات الموجودة بنفس المسار).
2. شغّل: `flutter pub get`
3. شغّل: `flutter run`  (أو `flutter build apk --release` لإنتاج ملف APK)

## ما تم في هذه الحزمة
- اسم التطبيق: كابتن بارتي (Manifest + العنوان + شاشة البداية)
- الألوان: #4F0E5E وتدرجاته (p50 ... p900) + تدرج رئيسي، في lib/theme/app_theme.dart
- اللغة العربية + اتجاه RTL + خط Cairo + تقويم عربي
- أيقونة التطبيق (Android + Web) وشعار داخل التطبيق من الأيقونة التي أرسلتها
- شاشة بداية + شاشة اختيار الدور (عميل / مقدم خدمة)
- الصفحة الرئيسية للعميل: بحث + 10 فئات + بطاقات مقدمي الخدمة
- لوحة مقدم الخدمة (الواجهة الثانية): تعديل الاسم والفئة والوصف والسعر والصور
  (من المعرض أو رابط) وأيام الحجز والخدمات وإخفاء/حذف/إضافة مقدم خدمة
- إدارة طرق الدفع: MTN كاش، سيرياتيل كاش، شام كاش، دفع بنكي، الدفع عند التسليم
- كل البيانات تُحفظ على الجهاز عبر lib/core/app_data.dart

## ملاحظات
- خط Cairo يُحمَّل من الإنترنت عند أول تشغيل ثم يُخزَّن.
- لوحة مقدم الخدمة حالياً بدون كلمة مرور (تحتاج خادماً لحماية حقيقية).
- الكود لم يُترجم/يُجرَّب على جهاز (لا يوجد Flutter في بيئتي)، فأرسل لي أي خطأ يظهر لك.
